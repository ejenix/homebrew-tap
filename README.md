# Ejenix Homebrew tap

```sh
brew install ejenix/tap/ejenix
```

The formula is generated from the published release manifest, so its `url` and
`sha256` describe the build the control plane is actually serving. It is
regenerated on every CLI release; do not hand-edit it.

Without Homebrew:

```sh
curl -fsSL https://get.ejenix.com/install.sh | sh
```

Docs: <https://ejenix.com>
